# Keyline sample documents

These six original PDFs are synthetic examples created for the Keyline permission-aware RAG project. Their names, figures, and company details are fictional. They are included so the repository and live portfolio site have reproducible, searchable example content.

## Files and app access

- 01 Employee Handbook and 02 Onboarding Policy: everyone in the workspace, matching their All Employees labels.
- 03 Project Apollo and 04 Project Risks: analysts and workspace admins, the closest roles this app can represent for Apollo project members and managers.
- 05 Financial Report 2026 and 06 Management Strategy 2026: workspace admins only. The app does not have distinct Finance, Management, or project-group roles, so these remain restricted.

The local app can load these files from the Library using “Load six sample documents.” PDFs are text-extracted and indexed; scanned image-only PDFs are not supported.
